EnsembleDistanceClassifier module#

An ensemble of distance metric classifiers, each using its own features.

class distclassipy.ensemble.EnsembleDistanceClassifier(metrics: list = None, feature_sets: dict = None, scale: bool = True, central_stat: str = 'median', dispersion_stat: str = 'std', reference: str = 'knn', n_neighbors: int = 15, weights: str = 'f1', cv: int = 5, max_features: int = None, n_jobs: int = None)#

Bases: ClassifierMixin, BaseEstimator

Combine distance metric classifiers, each using its own features.

Every metric gets its own DistanceMetricClassifier (a member) on its own subset of the features. Each member turns its distances to the classes into class probabilities, softmax(-distance / temperature), with the temperature calibrated on internal cross-validation. The ensemble’s probabilities are the weighted average of the members’ probabilities, with each member weighted by its internal cross-validated macro F1 score. No single metric has to be chosen, and better metrics count more.

Changed in version 0.4.1: Replaces the experimental per-quantile ensemble (feat_idx, n_quantiles), which used one metric per quantile of one feature.

Parameters:

  • metrics (list of str, optional) – The metrics to combine. Defaults to distances._UNIQUE_METRICS (16 metrics without formula-equivalent duplicates).

  • feature_sets (dict, optional) – Features to use for each metric, as {metric: [column indices]}, or {metric: [feature names]} when fit is given a DataFrame. Metrics without an entry get their features selected in fit by forward sequential feature selection, as in the DistClassiPy paper: macro F1 over cv folds, then the smallest subset whose score is within one standard deviation of the best. Entries for metrics not in metrics are ignored.

  • scale (bool, default=True) – Passed to every member (see DistanceMetricClassifier).

  • central_stat ({"median", "mean"}, default="median") – Passed to every member.

  • dispersion_stat ({"std", "iqr", "aiqr", "astd", "cdf"}, default="std") – Passed to every member.

  • reference ({"knn", "centroid"}, default="knn") – Passed to every member: the distance to a class is the mean distance to its n_neighbors nearest training objects (“knn”), or the distance to its centroid.

  • n_neighbors (int, default=15) – Passed to every member.

  • weights ({"f1", "uniform"}, default="f1") – Member weights: proportional to each member’s internal cross-validated macro F1, or equal.

  • cv (int, default=5) – Number of unshuffled stratified folds used for feature selection, member scores and temperature calibration.

  • max_features (int, optional) – Largest feature subset tried by the feature selection (default: all features). Lower values make fit faster.

  • n_jobs (int, optional) – Number of jobs for the feature selection (joblib convention).

Examples

>>> import distclassipy as dcpy
>>> from sklearn.datasets import make_classification
>>> X, y = make_classification(n_samples=300, n_features=5, random_state=0)
>>> clf = dcpy.EnsembleDistanceClassifier(metrics=["canberra", "clark"])
>>> clf.fit(X, y).predict(X[:3])
